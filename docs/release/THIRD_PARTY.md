# Credits and redistribution gate

See the package manifests and installed notices for React, Vite, Capacitor, PyTorch, MediaPipe, ONNX Runtime, Mosquitto and Arduino ESP32. Preserve the notices that apply to anything distributed. Retain Geoapify/OpenStreetMap attribution in results. Service API use is distinct from redistribution of provider assets.

Package metadata checked locally: React, Vite, Capacitor and ONNX Runtime Web declare MIT; the two MediaPipe packages declare Apache-2.0. The installed PyTorch distribution lists its main license and separate bundled notices. This is an inventory for review, not a complete audit of transitive packages or asset rights.

The source review archive does not include training recordings, checkpoints, exported weights, vendor runtime binaries or CIT/VieNeu voice assets. Obtain permission for team code and for any sourced/model data before publishing or sharing an APK with bundled weights. Verify credits and retain applicable notices before distributing builds. No project license has been selected or changed.
